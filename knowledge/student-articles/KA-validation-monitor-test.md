# Monitor Validation Test

**Status:** Classroom Accepted

**Knowledge Area:** Hardware

## Purpose

Temporary article used to validate the CIT-205 classroom Knowledge Base publishing workflow.

## Symptom

An external monitor does not display an image.

## Safe first checks

- Confirm the monitor has power.
- Confirm the display cable is seated securely.
- Confirm the correct monitor input is selected.

## Escalation

Stop and escalate if the issue requires opening equipment, changing protected configuration, or working outside assigned authority.
