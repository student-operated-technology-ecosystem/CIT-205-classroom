# Contributing to the CIT-205 Classroom Knowledge Base

This public repository accepts classroom Knowledge Article proposals through forks and pull requests.

## Required Path

**Word draft → instructor feedback → Markdown file → fork → branch → pull request → peer review → revision → instructor merge**

Students do not need membership in the SOTE organization or write access to the repository.

## File Location and Naming

Add proposed articles to `knowledge/student-articles/` using:

`KA-[GitHub-username]-[short-topic].md`

Do not assign an official numeric KA identifier. The instructor assigns controlled identifiers if and when an article is accepted into a governed knowledge system.

## Pull Request Expectations

A pull request must:

- contain one student's article or one focused revision;
- describe the assigned scenario;
- identify assumptions and unverified claims;
- contain no private, identifying, credential, internal-network, or student-record information;
- receive peer feedback and instructor review before merge.

## Authority Boundary

A contribution is classroom work. It does not grant student-worker status, organization membership, access to the private SOTE framework, infrastructure authority, GLPI administration, or production permission.
