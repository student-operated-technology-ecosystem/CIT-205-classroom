# Start Here — First Time in CIT-205 GitHub

**Goal:** Learn the four things you need today: repository, issue, file, and history.

## Step 1 — Sign In

Sign in to GitHub with your own account. Return to the [CIT-205 Classroom repository](https://github.com/student-operated-technology-ecosystem/CIT-205-classroom).

You should see the repository name and a **Public** label. You do not need to join the SOTE organization or receive infrastructure access.

## Step 2 — Know Where You Are

GitHub navigation follows:

**Organization → Repository → Folder → File**

Use the path near the top of the page to move back up. Selecting **CIT-205-classroom** always returns to the front door.

## Step 3 — Complete the Welcome Check-In

Open the pinned welcome issue supplied by your instructor. Add one comment containing:

- your preferred first name;
- one help-desk skill you want to improve;
- the sentence: **I understand that classroom participation does not make me a SOTE operator or student worker.**

Do not post an email address, student ID, password, schedule, or private information.

## Step 4 — Find a Knowledge Article

Open the [Knowledge Base](../knowledge/README.md), then open the no-display example. Identify:

- the problem;
- one question to ask;
- one troubleshooting step;
- one stop-and-escalate condition.

## Step 5 — Inspect History

At the top of the example article, select **History**. Open a revision and notice the lines that were added or removed. GitHub retains the record even after the current article changes.

## Completion Evidence

Submit the following through the instructor-designated course channel:

1. Your GitHub username.
2. A link to your welcome-issue comment.
3. The example article's status.
4. One sentence explaining what file history shows.
5. One navigation problem you encountered, or “No navigation problem.”

## Core Rule

Explore freely. Do not attempt to access, change, or administer private SOTE infrastructure. Ask when the assignment scope is unclear.
