## Teach the existing workflow

Reuse the existing DAY 14 portfolio publication assignment. Preserve its points, availability, submissions and no-due-date policy. This lesson adds no assessment points. The portfolio contains semester evidence; it is not an artificial final exam.

[View Alex Morgan’s Live Example Portfolio](https://student-operated-technology-ecosystem.github.io/CIT-205-classroom/examples/exemplary-portfolio/)

[Use this template](https://github.com/student-operated-technology-ecosystem/cit205-portfolio-template/generate). Students select their personal account, Public, and the exact name USERNAME.github.io. Upload a reviewed PDF to artifacts/, activate its matching link in index.html, commit to main, then Settings → Pages → Deploy from a branch → main → /(root) → Save. Future commits to main republish.
