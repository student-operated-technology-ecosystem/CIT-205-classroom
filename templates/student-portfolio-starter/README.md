# CIT-205 Student Portfolio Starter

This is a **starter template**, not a completed student portfolio. Copy `index.html`, `style.css`, and the `artifacts/` directory into your own public GitHub Pages repository.

## Student publishing checklist

1. Follow the [ACE Portfolio Publication Mission](../../assignments/ACE-portfolio-publication-mission.md).
2. Create a public repository named `YOUR-GITHUB-USERNAME.github.io` under **your** GitHub account.
3. Upload `index.html` and `style.css` into the **root** of that repository. Create `artifacts/` and upload your own reviewed, redacted PDFs.
4. Replace every `YOUR NAME`, introductory paragraph, sample explanation, GitHub URL, and LinkedIn URL.
5. Enable **Settings → Pages → Deploy from a branch → main → /(root)**.
6. Open `https://YOUR-GITHUB-USERNAME.github.io/` and test all links.
7. Submit the live URL and repository URL to Blackboard.

**Important:** The example HTML links point to PDF filenames that are not included in the starter. Those links will not work until you upload your actual artifacts. This is intentional: you must demonstrate your own work.

The [Alex Morgan example](../../examples/exemplary-portfolio/) is a fictional quality reference, not student work to copy.

## Instructor classroom demonstration
Walk through account/repository creation, show `index.html` and `style.css` in the root, upload one safely redacted artifact, publish via Pages, and open the resulting website in a private window. Then show how to replace a broken link and verify the repair.
